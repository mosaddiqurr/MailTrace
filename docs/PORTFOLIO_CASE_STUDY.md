# Portfolio case study

MailTrace makes raw email evidence easier to investigate while retaining the original detail and its limitations. Its FastAPI/SQLite backend performs bounded email parsing, reported-authentication extraction, sender alignment, delivery reconstruction, static attachment hashing, URL inventory, and explainable assessment.

The React/TypeScript interface connects a compact evidence intake with structured reports, local history, methodology, settings, and exports. Its procedural email hero uses an OffscreenCanvas worker, cached geometry, batched particles, and visibility-aware cleanup. Static sections skip rerenders during typing. The [recorded performance work](PERFORMANCE.md) includes matched Lighthouse audits and a slow-CPU input-response comparison rather than relying only on visual impressions.

The project demonstrates API design, bounded parsing, persistence and migrations, responsive product design, browser-worker lifecycle management, safe exports, and automated backend and real-browser validation. Private evidence and generated artifacts stay out of Git; documentation screenshots use isolated synthetic fixtures. MailTrace does not independently verify historical authentication, perform malware analysis, or prove receiver ownership from message bytes alone.
