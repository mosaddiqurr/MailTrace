# Exports

PDF provides a portable readable report. For full `.eml` evidence, PDF and HTML include MIME topology, safe body summaries, attachment metadata and hashes, and URL display-versus-destination evidence without rendering HTML, executing attachments, or fetching links. Header-only reports explicitly state that MIME/body evidence is unavailable instead of presenting empty analysis sections.

JSON preserves structured fields. CSV provides observation rows and neutralises values beginning with formula characters. Plain text supports notes and ticketing systems. HTML retains a restrictive CSP and escapes all evidence content. Bundle ZIP contains reports and retained originals when available.
