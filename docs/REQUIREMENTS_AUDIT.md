# Requirements Audit

The main workflow supports `.eml` upload, pasted headers, result review, history, deletion, raw evidence, and PDF/JSON/CSV/text/HTML/bundle exports. Sender identity, reported authentication, alignment, ARC evidence, ordered hops, MIME, attachments, URLs, observations, assessment, confidence, warnings, and limitations are exposed.

Safety controls prohibit execution and network fetching, bound parsing, preserve hashes and bytes, neutralise CSV formulas, confine paths, and redact internal exceptions. The UI has four navigation destinations, semantic controls, keyboard upload, responsive layouts, visible focus, non-colour labels, and reduced-motion handling.

Not claimed or implemented: malware scanning, dynamic sandboxing, live reputation, geolocation, mailbox access, independent DKIM/SPF/DMARC verification, or guaranteed verdicts.
